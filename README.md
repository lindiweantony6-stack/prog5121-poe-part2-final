# QuickChat - PROG5121 PoE Part 2

Console chat application written in Java (Maven).

## Features
- Registration and login (from Part 1)
- Send, disregard or store messages
- Message ID, message hash and recipient number checks
- Stored messages are saved in messages.json
- JUnit 5 unit tests, run automatically with GitHub Actions

## Run the tests
mvn test
